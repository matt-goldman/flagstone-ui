# Archive

- **[decisions/](decisions/)** — Architecture Decision Records (ADRs) documenting design rationale.
- **[project/](project/)** — Earlier roadmaps and implementation-status tracking.
- **[bootstrap-converter/](bootstrap-converter/)** — Docs for the Bootstrap-to-FlagstoneUI converter. The converter now lives in its own repository.
- **[theme-prompts/](theme-prompts/)** — AI prompts for generating themes. Theme tooling now lives in its own repository.
- **[token-tooling/](token-tooling/)** — The machine-readable token catalog, schemas, and generated contracts used by theme/agent tooling.
- Loose specs and plans (`spec-fsshell.md`, `technical-plan.md`, `rethinking-tokens.md`, etc.) from earlier development.
